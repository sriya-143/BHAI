OPERATION BHAI DOOJ - QUICK START

1. Extract the ZIP file.
2. Keep index.html, style.css, script.js and the images folder together.
3. Open index.html in Chrome, Edge, Safari or Firefox.

PROJECT FILES
- index.html: all website pages and content
- style.css: design, backgrounds, typography and mobile layout
- script.js: loading animation, navigation, discount rejection page, scratch-card game and final celebration
- images/festival-home-bg.webp: optimized version of your uploaded first image, used on first and final pages
- images/tax-page-bg.webp: optimized tax department page background
- images/report-card-bg.webp: optimized report card page background
- images/scratch-page-bg.webp: optimized four scratch-card page background

NOTES
- Internet is required for the Google Fonts and the Tenor GIF embed.
- The website does not collect data or make real payments.

- Exactly one scratch-card prize can be claimed. The other three reveal as NOT WON.
